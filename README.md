# とあるシリーズ総合ガイド

鎌池和馬原作「とある」シリーズ（とある魔術の禁書目録 / とある科学の超電磁砲 / とある科学の一方通行）の非公式ファンガイドサイトです。

Wikipediaおよび各公式アニメサイト（toaru-project.com）の公開情報をもとに、三シリーズの概要・世界観・登場人物・アニメ作品情報をまとめています。

- 公開URL: https://keniti2026.github.io/toaru-guide-site/
- 技術構成: ビルド工程なしの静的サイト（HTML / CSS / JavaScript のみ）

## ローカル確認

リポジトリのルートで簡易HTTPサーバーを起動して確認できます。

```
python -m http.server 8000
```

起動後、ブラウザで `http://localhost:8000/` を開いてください。

## ファイル構成

- `index.html` — サイト本体（1ページ構成、セクションごとにアンカーリンクでナビゲーション）
- `style.css` — レスポンシブなダークテーマのスタイル
- `script.js` — ナビ開閉・キャラクタータブ切り替え・キャラクターカードのタップ詳細表示
